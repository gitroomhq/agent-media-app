1 · The DSN (the “where do events go” URL)

a
Open Project Settings → Client Keys (DSN). Direct link: https://agentmedia.sentry.io/settings/projects/ …click your project, then in the left menu under SDK Setup choose Client Keys (DSN).
b
Copy the value labelled DSN. It looks like: https://abc123def456@o4509999.ingest.us.sentry.io/4510000 This is the only required value to turn capture on. It's not a secret in the dangerous sense — it only lets clients send events — but treat it as config, not public copy.

2 · The project slug (short name in the URL)

a
On the same Projects page (…/settings/projects/), the slug is the short id under the project name — e.g. javascript-nextjs or whatever you named it. It's also in the URL when you open the project's settings.

3 · The auth token (lets the build upload source maps so stack traces are readable)

a
Open Organization Auth Tokens: https://agentmedia.sentry.io/settings/auth-tokens/
b
Click Create New Token. Org auth tokens come pre-scoped for releases & source-map upload (project:releases, org:read, project:write) — you don't need to pick scopes manually.
c
Copy it immediately — it starts with sntrys_… and is shown only once. secret Treat this one like a password.

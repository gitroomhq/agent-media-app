Skills — what I learned + concrete refactor plan

The current Claude Skills format (2026-05)

Key concepts:
  • A plugin is the unit of install. claude /plugin install <github-url>.
  • A plugin has a .claude-plugin/plugin.json manifest at its root.
  • A plugin can contain many skills under skills/<name>/SKILL.md.
  • A plugin can ship its own MCP server via .mcp.json.
  • There is no Anthropic Skills Hub yet — distribution is github URLs + a community marketplace at @claude-community.

SKILL.md frontmatter

FieldNotes
nameOptional; defaults to directory name.
descriptionRecommended. Drives Claude's auto-invocation. Cap ~1500 chars.
when_to_useExtra trigger context.
allowed-toolsTools the skill may use without per-call prompt.
disable-model-invocationtrue = manual-only (slash command).
user-invocablefalse = hidden from / menu.
pathsGlob patterns that auto-trigger the skill when matching files are open.
model, effortPer-skill overrides.

Migration plan

Step 1 — Plugin manifest

// .claude-plugin/plugin.json
{
  "name": "agent-media",
  "description": "AI UGC video production — primitives + composed skills for portraits, character sheets, talking-head videos, and TikTok-style captions, all backed by Temporal + Seedance 2.0.",
  "version": "1.0.0",
  "author": { "name": "yuvalsuede" },
  "homepage": "https://agent-media.ai",
  "repository": "https://github.com/yuvalsuede/agent-media",
  "license": "Apache-2.0"
}

Step 2 — One SKILL.md per vNext skill

Convert each registry entry into a dedicated skills/<slug>/SKILL.md. The skill body teaches Claude:

  • What the skill does + when to use it.
  • Required + optional inputs (with the exact JSON shape).
  • How to call it via the MCP tool or the REST endpoint.
  • How to poll the result.
  • Examples lifted from our verified test runs (so Claude has concrete prompts to imitate).

5 skill markdowns: make-portrait, make-character-sheet, make-simple-selfie, make-subtitles, make-ugc-video.

Step 3 — MCP integration (.mcp.json)

{
  "mcpServers": {
    "agent-media": {
      "command": "npx",
      "args": ["-y", "@agentmedia/mcp-server@latest"],
      "env": { "AGENT_MEDIA_API_KEY": "${AGENT_MEDIA_API_KEY}" }
    }
  }
}

So installing the plugin auto-wires the MCP server (which proxies to https://api.agent-media.ai/mcp).

Step 4 — Bump the MCP server

Cut @agentmedia/mcp-server@0.6.0 with the vNext skills surfaced in its tools/list. Today the HTTP /mcp route lists them correctly; the stdio package just needs a rebuild + publish.

Step 5 — README install instructions

# NEW
claude /plugin install github.com/yuvalsuede/agent-media

# OR via community marketplace once approved
claude /plugin install @claude-community/agent-media

Step 6 — Repurpose the root SKILL.md

Keep a small root SKILL.md as a routing pointer:

  • Lists what's inside the plugin (the 5 vNext skills + the legacy v2 skill).
  • Points users at skills/make-ugc-video/SKILL.md for the all-in-one flow.
  • Drops the legacy v2 CLI duplication — that already lives in skills/agent-media-v2/SKILL.md.

Step 7 — Submit to @claude-community

At claude.ai/settings/plugins/submit — paste the github URL. Adds discoverability without changing the install path.

2 · Factual errors to fix handover wrong

1 Workflow types are PascalCase: PortraitGpt2Workflow, MakeUgcVideoWorkflow… They are camelCase: portraitGpt2Workflow, characterSheetGpt2Workflow, simpleSelfieWorkflow, subtitlesWorkflow, wireframeGpt2Workflow, makeUgcVideoWorkflow (registry.ts lines 122-172)
2 API host is agent-media.ai; MCP HTTP at agent-media.ai/mcp Real API base is https://api.agent-media.ai (mcp-server index.ts:44). agent-media.ai/mcp 308-redirects to /skill. The HTTP MCP surface is api.agent-media.ai/mcp (returns 401, i.e. it exists & is gated). Unauthed public list = web proxy agent-media.ai/api/v1/public/skills.
3 "MCP: HTTP transport at /mcp, stdio via npx" (conflated) The npm @agentmedia/mcp-server is stdio-only ("running on stdio", index.ts:704) and calls the REST API. The HTTP /mcp is a separate api-v2 surface. Two different things.
4 Run status path GET /v1/skill-runs/<id> Actual path is /v1/skills/runs/<id> (mcp-server index.ts:590)
5 primitive_runs columns: skill_slug, workflow_id, temporal_run_id, output, error, credits_deducted Actual columns: id, user_id, skill_run_id, primitive_id, status, input, idempotency_key, provider_task_id, estimated_credits_usd, actual_credits_usd, error_code, error_message, started_at, finished_at, created_at, updated_at (+credits_deducted added later). There is no workflow_id / temporal_run_id / output / error / skill_slug. Outputs live in primitive_artifacts.
6 status enum = queued | running | succeeded | failed | cancelled = submitted | running | succeeded | failed | canceled (one L). "queued" does not exist (migration line 25).
7 Credits tracked as a single credits_deducted Base table tracks USD: estimated_credits_usd + actual_credits_usd (numeric). credits_deducted (integer) was bolted on later. Both exist.

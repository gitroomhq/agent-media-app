Activate the gitroomhq mirror

Plugin is built and pushed to yuvalsuede/agent-media. The GitHub Action that mirrors public-skill/ → gitroomhq/agent-media is committed but disabled until you provision two things below. Once active, every push to main that touches public-skill/** mirrors automatically.

Total time: ~5 minutes. Both repos are yours, so no waiting on anyone.

1 Make sure gitroomhq/agent-media repo exists and is empty (or willing to be force-pushed)

The workflow does git push -f to gitroomhq/agent-media:main. If the repo already has content you care about, back it up first.

If it doesn't exist yet: create it on GitHub under the gitroomhq org as Public.

2 Generate a deploy key locally

ssh-keygen -t ed25519 -C "agent-media-mirror" -f ~/.ssh/agent_media_mirror -N ""

This creates two files:

  • ~/.ssh/agent_media_mirror — private key
  • ~/.ssh/agent_media_mirror.pub — public key

3 Add the PUBLIC key to gitroomhq/agent-media as a deploy key

  1. Open https://github.com/gitroomhq/agent-media/settings/keys
  2. Click Add deploy key.
  3. Title: agent-media-mirror
  4. Key: paste the contents of ~/.ssh/agent_media_mirror.pub: 
    cat ~/.ssh/agent_media_mirror.pub
  5. Check the "Allow write access" box (this is the one that's easy to miss).
  6. Save.

4 Add the PRIVATE key to yuvalsuede/agent-media as a secret

  1. Open https://github.com/yuvalsuede/agent-media/settings/secrets/actions
  2. Click New repository secret.
  3. Name: GITROOM_DEPLOY_KEY
  4. Secret: paste the contents of ~/.ssh/agent_media_mirror: 
    cat ~/.ssh/agent_media_mirror
  5. Save.

5 Add a repo variable to enable the workflow

  1. Open https://github.com/yuvalsuede/agent-media/settings/variables/actions
  2. Click New repository variable.
  3. Name: MIRROR_PUBLIC_SKILL_ENABLED
  4. Value: true
  5. Save.

The workflow is gated on this variable so it can't run by accident if the secret leaks.

6 Delete the private key from your laptop

rm ~/.ssh/agent_media_mirror ~/.ssh/agent_media_mirror.pub

GitHub keeps the secret encrypted; you don't need a local copy.

7 Kick the workflow

Either push any change under public-skill/ on the private repo, or trigger manually:

  1. Open https://github.com/yuvalsuede/agent-media/actions/workflows/mirror-public-skill.yml
  2. Click Run workflow → Run workflow.

When it succeeds, gitroomhq/agent-media contains .claude-plugin/, .mcp.json, README.md, skills/, reference/, LICENSE.

After that you can claude /plugin install github.com/gitroomhq/agent-media from any machine and it pulls the latest. Ping me when steps 1–7 are done and I'll fire one install + smoke-test the plugin.

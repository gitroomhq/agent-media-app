Step 3 — Trigger one smoke test (still SIMULATE_OPENAI=true)

Two options to trigger:

Option A — via api-v2 (recommended; exercises the full path)

  1. Set VNEXT_PRIMITIVES_ENABLED=true on the api-v2-production service in Railway → redeploy.
  2. From your machine, with a valid auth token: 
    curl -sS -X POST https://api.agent-media.ai/v1/primitives/portrait_gpt2 \
  -H "Authorization: Bearer $YUVAL_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: smoke-$(date +%s)" \
  -d '{
    "description": "a friendly young woman smiling at the camera, soft daylight",
    "aspect_ratio": "1:1",
    "realism_target": "natural"
  }'
  3. Expect HTTP 202 with {run_id, workflow_id, status:"submitted"}.
  4. Watch the Workflow in Temporal Cloud UI complete → Activity returns the stub PNG URL.
  5. Verify the rows in Supabase: 
    SELECT id, status, actual_credits_usd FROM primitive_runs WHERE id = '<run_id>';
SELECT url, kind, bytes FROM primitive_artifacts WHERE primitive_run_id = '<run_id>';
  6. Open the artifact URL — it'll be the 1×1 stub PNG (proves R2 upload + URL routing works).

Option B — direct via Temporal CLI (skips api-v2 entirely)

Faster if you don't want to flip the api-v2 env flag yet:

temporal workflow start \
  --task-queue primitive-vnext-v1 \

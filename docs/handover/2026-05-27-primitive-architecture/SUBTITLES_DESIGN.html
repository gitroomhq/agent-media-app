Primitive #4 — subtitles

Takes any vNext video URL, burns TikTok-style captions onto it, returns a new R2 URL. Auto-transcribes via Whisper when no transcript is given; otherwise uses the provided text (the script we already have for simple_selfie / make_ugc_video).

Contract

InputTypeNotes
video_urlstring (R2 prefix only)Required.
transcriptstring ≤ 5000 charsOptional. If supplied, we still run Whisper to get word-level timings, but force the words to match the transcript.
stylehormozi \| tiktok \| minimalDefault hormozi. Maps to an ASS preset.
language2-char ISO (e.g. en)Optional Whisper hint.
Output
video_urlstringR2 MP4 at vnext/primitive-runs/<run_id>/subtitled.mp4
providerwhisper-ffmpeg

Activity flow

  1. Validate input. SSRF guard on video_url (R2 prefix).
  2. Retry-safety + budget caps. Estimated $0.05 (Whisper) + minimal ffmpeg time.
  3. Upsert primitive_runs; deduct credits (15 credits ≈ $0.09 margin).
  4. Download the source MP4 to a temp dir.
  5. Extract audio with ffmpeg -vn -ac 1 -ar 16000 -f wav.
  6. Call OpenAI Whisper (whisper-1) with response_format: verbose_json + timestamp_granularities: ['word']. If user passed a transcript, post-align to it.
  7. Build an ASS subtitle file using the chosen style preset (lifted from media-worker-v2/src/ass-generator.js).
  8. FFmpeg burn: ffmpeg -i input.mp4 -vf "ass=subs.ass" -c:a copy output.mp4.
  9. Upload to R2 under vnext/primitive-runs/<run_id>/subtitled.mp4.
  10. Insert primitive_artifacts (kind = subtitled_video) and finalize.

What needs to change in the worker container

Current primitive-worker-vnext ships with no FFmpeg binary. Two options:

  1. Add a Dockerfile that installs ffmpeg + the Node runtime. ~5 min change, larger image (~200 MB extra).
  2. Use the Nixpacks "apt" hook — append {"packages":["ffmpeg"]} via nixpacks config. No Dockerfile churn.

Recommendation: (1) Dockerfile — explicit + matches how media-worker-v2 ships ffmpeg.

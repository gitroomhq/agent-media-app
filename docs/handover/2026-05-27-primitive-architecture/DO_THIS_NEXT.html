Step 3 — create the Railway service

Migration ✓ applied. On to creating the new Railway service.

This makes a new service alongside temporal-worker and media-worker-v2. It will run the new primitive worker. We're starting it in simulate mode — no real OpenAI calls yet.

3.1 — Open Railway and create the service

1 In your Railway dashboard, open the same agent-media production project (the one with temporal-worker, media-worker-v2, api-v2).
2 Top-right: click "+ Add" → "GitHub Repo".
3 Pick yuvalsuede/agent-media.
4 In the service that appears, click Settings (gear icon at top of the service detail pane).

3.2 — Set the basics

FieldValue

This is a Temporal worker — it does not need a public domain. Don't expose any port. Don't generate a domain.

3.3 — Set the env variables

In the new service: Variables tab → paste these. For R2 and Supabase values, use the "Add from another service" feature and copy from media-worker-v2 or api-v2 — don't paste secrets into chat or random fields.

TEMPORAL_ADDRESS=us-west-2.aws.api.temporal.io:7233
TEMPORAL_NAMESPACE=quickstart-agent-media.v5v8r
TEMPORAL_API_KEY=<same Temporal API key as before>
TEMPORAL_TLS=true
TEMPORAL_PRIMITIVE_TASK_QUEUE=primitive-vnext-v1

OPENAI_API_KEY=<same OpenAI key as before>
OPENAI_IMAGE_MODEL=gpt-image-2

R2_ACCOUNT_ID=<copy from media-worker-v2>
R2_ACCESS_KEY_ID=<copy from media-worker-v2>
R2_SECRET_ACCESS_KEY=<copy from media-worker-v2>
R2_BUCKET=agent-media-outputs
R2_PUBLIC_URL=https://pub-16e2ed8f6be84691845e91436920ce0a.r2.dev

SUPABASE_URL=<copy from api-v2>
SUPABASE_SERVICE_ROLE_KEY=<copy from api-v2>

PRIMITIVE_CAP_USD=0.50
RUN_CAP_USD=5.00
DAY_CAP_USD=20.00

SIMULATE_OPENAI=true
SIMULATE_OPENAI=true is critical. Keep it true for now — that's what stops any real OpenAI spend until we test the wiring.

3.4 — Deploy

1 Hit Deploy on the new service.
2 Watch the Build Logs. You should see pnpm install, then schema build, then primitive-worker-vnext build.
3 Once build is done, watch the Deploy Logs. You should see one line like:
[primitive-worker-vnext] listening namespace=quickstart-agent-media.v5v8r queue=primitive-vnext-v1 simulate=true

Concrete examples

1) Raw REST (curl, any language)

curl -sS -X POST https://api.agent-media.ai/v1/skills/make_ugc_video/run \
  -H "Authorization: Bearer $AGENT_MEDIA_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: my-clip-1" \
  -d '{
    "description": "a friendly young man, soft daylight",
    "script": "Honestly this changed my morning routine.",
    "duration": 5
  }'
# → 202 { "skill_run_id": "...", "workflow_id": "...", "status": "submitted" }

curl -sS https://api.agent-media.ai/v1/skills/runs/<skill_run_id> \
  -H "Authorization: Bearer $AGENT_MEDIA_API_KEY"

2) Claude.ai / Cursor via MCP HTTP

In the MCP connector setup the user pastes:

URL:      https://api.agent-media.ai/mcp
Auth:     Authorization header — Bearer <their ma_* token>

Once connected, the assistant sees make_portrait, make_character_sheet, make_simple_selfie, make_subtitles, make_ugc_video in its tool list. Calling any of them returns the run_id + a hint to poll GET /v1/skills/runs/<id>.

3) Claude Desktop / Code via stdio

// .config/claude-desktop/config.json
{
  "mcpServers": {
    "agent-media": {
      "command": "npx",
      "args": ["-y", "@agentmedia/mcp-server"],
      "env": { "AGENT_MEDIA_API_KEY": "ma_..." }
    }
  }
}

4) Claude Code skill install

SKILL.md is the entrypoint Claude Code reads when a user installs this repo as a skill (claude skills add github.com/yuvalsuede/agent-media in current Claude Code semantics). The skill teaches Claude how to call agent-media CLI and the REST endpoints with the user's credentials.

What we still owe external agents (gaps)

  • Public skill discovery page — a /docs/skills or /skills URL on agent-media.ai that lists every skill with its JSON schema. Today the GET /v1/skills JSON is auth-gated; an unauthenticated landing page would help SEO + agent crawlers find us.
  • OpenAPI publish — our /openapi.json already contains the vNext routes. Hosting it at a stable public URL + linking from agent-media.ai/docs is useful for tool-using agents that scrape OpenAPI.
  • Stdio MCP server is at v0.5.0 — pre-vNext. Needs a release bump so users running it locally get the new skills via stdio too. (Currently they get them via the HTTP relay it embeds, but explicit metadata in the package would help.)

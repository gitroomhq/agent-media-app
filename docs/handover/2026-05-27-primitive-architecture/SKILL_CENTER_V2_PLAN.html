Skill Center — what's there + what to build

What's live today (`/dashboard/skills`)

  • One page. Lists skills from GET /v1/skills. Cards expand inline into a form.
  • Submit → 202 → polls every 4s. Shows active runs at top with per-step artifact links.
  • 5 hand-coded forms, one per skill.
Gaps: no persistent run history, no per-skill detail page, no MCP/SDK install snippets, no cost or time info on the card, no icons, no search, no empty-state guidance for new users.

What I would NOT build in this round

  • Search. 5 skills doesn't need search; revisit at 15+.
  • Categories / tags. Same reason.
  • Install/uninstall flow. Future, when we accept third-party skills.
  • Skill ratings / reviews. Future.
  • Editing skill metadata in the UI. Registry is the source of truth.
Pick one:
  1. Full v2 (items 1–7 above) — ~3 hrs. Three pages. Best end-state.
  2. Lean v2 — items 1, 2, 5, 6 only (library refresh + detail page with form). Skip the dedicated run timeline page (active runs still live on the library page like today). ~1.5 hrs.
  3. Polish only — items 1, 5, 6 (cards + icons + cost) without breaking the single-page flow. ~45 min.

I'd pick Lean v2 — the detail page is where the most value lives (MCP setup snippets + a focused form). The dedicated run timeline page is nice but the existing inline active-run cards already cover most of it.

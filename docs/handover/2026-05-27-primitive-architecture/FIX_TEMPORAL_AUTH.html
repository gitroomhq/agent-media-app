The worker can't connect to Temporal

Error: Jwt is not in the form of Header.Payload.Signature with two dots and 3 sections

That means the Temporal Cloud gateway received a value for the API key, but it wasn't a valid JWT. The token I have on file IS a valid JWT (3 sections separated by 2 dots), so something got mangled between Railway's env vars and the worker.

Most likely cause: quotes around the value in Railway

If you pasted the token wrapped in quotes ("eyJ..."), Railway stores the quotes as part of the value and Temporal rejects it.

1. Open Railway → primitive-worker-vnext → Variables

Find TEMPORAL_API_KEY.

2. Check three things

  1. No surrounding quotes — the value should start with eyJ, not "eyJ.
  2. No line breaks — the whole token must be on a single line. JWTs are long; if Railway wrapped it visually, that's fine, but make sure no actual newline was pasted in.
  3. No trailing whitespace — Railway sometimes hides trailing spaces. Click into the value, hit End, make sure the cursor is right after the last character.

3. Also confirm the value matches this shape

Three sections separated by exactly two dots:

eyJ………FoifQ.eyJ………NSJ9.L9v………Y0Q

Counting dots from your token: should be exactly 2.

4. Save the variable + redeploy

Railway will auto-redeploy when you save the variable. Watch the logs.

Success line:

[primitive-worker-vnext] listening namespace=quickstart-agent-media.v5v8r queue=primitive-vnext-v1 simulate=true

If the error persists with the same JWT message

Generate a fresh API key in Temporal Cloud and paste that one instead. Sometimes the original copy-paste lost a character at the end.

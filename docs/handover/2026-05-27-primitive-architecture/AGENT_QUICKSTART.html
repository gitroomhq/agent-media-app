Get your agent making videos

Three things: (1) have credits, (2) connect your agent to agent-media, (3) call one skill. The headline skill is make_ugc_video — description + script → finished captioned video.

Step 0 — Credits + an API key

  • Buy credits on the dashboard (app.agent-media.ai → Add Credits). A 10s talking-head is ~280 credits.
  • Get your API key: run agent-media login (opens a browser, stores a ma_… token), or grab it from the dashboard. Every surface authenticates with that Bearer token.

Step 1 — Connect your agent (pick one)

A) Claude Code / Cursor — the plugin easiest

claude /plugin install github.com/gitroomhq/agent-media

That installs the skills + the MCP tools. Then just tell the agent in plain language:

"Make a 10-second UGC video of a friendly 28-year-old woman saying:
 'Okay, this app changed my whole morning routine — you have to try it.'"

The agent picks make_ugc_video, runs it, and hands you back the video URL.

B) Any MCP agent (n8n, custom, Windsurf…)

Add the MCP server to your agent's .mcp.json:

{
  "mcpServers": {
    "agent-media": {
      "command": "npx",
      "args": ["-y", "-p", "@agentmedia/mcp-server@latest", "agent-media-mcp"],
      "env": { "AGENT_MEDIA_API_KEY": "ma_your_key_here" }
    }
  }
}

The agent now sees tools like make_ugc_video, make_simple_selfie, make_lip_sync, etc. (loaded live — always current).

C) Terminal / scripts — the CLI

npm i -g agent-media-cli
agent-media login
agent-media skills run make_ugc_video --input @video.json
agent-media skills status <run_id>

D) Raw REST (any language)

curl -X POST https://api.agent-media.ai/v1/skills/make_ugc_video/run \
  -H "Authorization: Bearer ma_your_key" \
  -H "Content-Type: application/json" \
  -d '{ "description": "a friendly 28-year-old woman, soft daylight",
        "script": "Okay this changed my morning routine, you have to try it.",
        "duration": 10, "subtitles": true }'

Step 2 — One call makes the whole video

make_ugc_video runs the full pipeline in one request: portrait → character sheet → lip-synced talking-head → burned-in captions.
  • Identity: give EITHER description (text→video) OR portrait_url (R2-hosted image) OR an uploaded image.
  • script: what they say (2–4 words/sec of duration). duration: 5 / 10 / 15.
  • subtitles: true/false + subtitles_style (hormozi / tiktok / minimal).
Returns { skill_run_id } → poll GET /v1/skills/runs/<id> → when status: "succeeded", final_output.video_url is your MP4.

Variations

  • Bring your own voice: make_lip_sync — give a face image + your own audio recording; it lip-syncs the face to YOUR audio (no TTS).
  • Step-by-step (approve each stage): make_portrait → make_character_sheet → make_simple_selfie → make_subtitles.
  • Reuse a character: keep the character_sheet_url and feed it to make_simple_selfie for every new script — same person, instantly.

That's it

Connect once (plugin / MCP / CLI / REST), make sure there are credits, call make_ugc_video. The agent gets a finished vertical UGC video back. All 7 skills are live and self-describe their inputs via MCP tools/list, so an agent can discover them with no extra docs.

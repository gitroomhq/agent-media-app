Primitive #3 — simple_selfie

Generates a short vertical UGC selfie video of the SAME person from a character sheet, with native lip-synced audio of a given script. No product, no object held, framed waist-up.

Haiku instruction (system prompt)

You build the prompt sent to Seedance 2.0 (BytePlus ARK) for a SIMPLE VERTICAL SELFIE VIDEO of the person in the reference image (a character sheet).

Hard rules:
- Output ONE single sentence. Comma-separated clauses. Final period.
- No paragraphs, no markdown, no quotes, no preamble. Output ONLY the prompt.
- Identity locks to the reference image — same person.

Mandatory clauses (paraphrase, do not omit):
- Framing: vertical 9:16 TikTok-style selfie, framed waist-up (full top half visible), hands free, NOT holding anything, NOT holding a phone, looking directly at the camera.
- Camera feel: handheld iPhone front-camera vibe, subtle breathing motion, micro head tilts, candid not staged.
- Subject says the script VERBATIM with natural lip-sync, natural pauses, breathing, micro filler beats where appropriate. Do not paraphrase the script.
- Realism: same skin texture, visible pores, subtle asymmetries, micro-expressions as the reference.
- Setting: use the user's location hint if provided; otherwise neutral bright daylight indoor space.
- Pose: use the user's pose hint if provided; ALWAYS no object held.
- Constraints: no text overlay, no captions, no watermark, no logo.

Embed the user's script as the spoken line. Embed location and pose hints faithfully when provided.

Schema-level pacing enforcement

Zod refine on the input ensures script word count fits 2–4 words per second of duration:

const wc = s.trim().split(/\s+/).filter(Boolean).length;
const minWords = duration * 2;
const maxWords = duration * 4;
// wc must be in [minWords, maxWords]

What is NOT in this primitive

  • Subtitles burn-in. That's a separate primitive (next on the roadmap: subtitles, TikTok font style). For V1 the video has spoken audio only.
  • Product/object holding. Explicitly forbidden here. A future product_selfie primitive will accept a product image and orchestrate the holding interaction (per the agent-media product UGC workflow).
  • Multi-scene cuts. One continuous shot only.

Provider risk to flag

Saved memory no-byteplus-for-photoreal says BytePlus ModelArk privacy filter has rejected real-person reference images. But the existing prod media-worker-v2/v2/selfie-pipeline.js already uses BytePlus successfully with gpt-image-2 reference outputs. Theory: BytePlus accepts AI-generated portraits (our case) but blocks raw human photos. Will verify on the first live run.

If BytePlus rejects: fall back to EvoLink Seedance or other Seedance provider — existing media-worker-v2 has alternate dispatch paths to reuse.
